# Before/After fine-tuning demo

This shows the dataset actually *does something*: it fine-tunes a small base
model on the dataset produced by Nemotron Data Forge and compares answers
**before** (base model) vs **after** (fine-tuned), with an offline quality
report.

Nothing here needs an API key, and it fits a **free Google Colab T4 GPU**.

## What it does

1. Loads a dataset (`outputs/dataset-*.jsonl` from the pipeline, or the bundled
   sample fixture).
2. Splits it into train/eval.
3. Trains a LoRA adapter on a small instruct model (default
   `Qwen/Qwen2.5-0.5B-Instruct`).
4. Generates eval answers **before** (`model.disable_adapter()`) and **after**
   (adapter enabled) — same weights, so the only difference is fine-tuning.
5. Scores both with offline metrics and writes `before_after.md` / `.json`.

> The bundled `sample_dataset.jsonl` is a small, hand-written, verifiable
> fixture about **Python fundamentals**. It exists only so the notebook can be
> exercised end-to-end before any model keys exist. The real demo must use the
> dataset generated by the pipeline (`outputs/dataset-*.jsonl`).

## Metrics (offline, reference-based)

| Metric | Meaning |
| --- | --- |
| Token F1 vs reference | Overlap between the answer and the reference answer |
| Keyword recall | Share of the reference's key terms that appear in the answer |
| Length closeness | 1.0 when answer length matches the reference |
| Format adherence | 1.0 when the answer respects the requested format |

These are deterministic heuristics for a quick before/after read. The pipeline's
Nemotron 3 Ultra grader remains the primary quality signal for the dataset
itself.

## Run on Colab

Open `colab_before_after.ipynb` in Colab, choose a GPU runtime, and run all
cells. It installs the dependencies, clones this repo, picks the newest
generated dataset (or the sample), trains, and displays the report.

## Run locally (needs a GPU or patience on CPU)

```bash
pip install "torch>=2.1" "transformers>=4.40" "peft>=0.10" "datasets>=2.18" "accelerate>=0.30"

# Validate a dataset with no heavy deps:
python -m finetune.train_lora --dataset finetune/sample_dataset.jsonl --check

# Train + evaluate:
python -m finetune.train_lora \
  --dataset outputs/dataset-<stamp>.jsonl \
  --base-model Qwen/Qwen2.5-0.5B-Instruct \
  --epochs 3 --out finetune_output
```

Outputs land in `finetune_output/`: `adapter/` (the LoRA weights),
`before_after.md`, and `before_after.json`.

## Layout

```
finetune/
  dataset_utils.py   load / split / prompt-building (pure, unit-tested)
  scoring.py         token F1, keyword recall, length/format metrics (pure)
  report.py          before/after Markdown + JSON report (pure)
  train_lora.py      LoRA training + generation (torch/transformers, lazy import)
  sample_dataset.jsonl
  colab_before_after.ipynb
```
